Copperwire Extraction

An intern in cybersecurity at the London police department has discovered that files were exfiltrated from their database. He managed to retrieve the queries used but needs help from someone really skilled in cybersecurity to figure it out!

Writeup

Here is the step by step solution

  1. Download the pcap file
  2. Open it with Wireshark

If we refer to the description of the challenge, we see that there seems to be an exfiltration.

We see that we have a cookie in the header which contains a base64 value

If we convert it we discover some interresting data

It seems to be a PNG file, if we open it we will find a picture wich contains a letter, probably the flag's first few characters

Let's continue with the second cookie !

It is not recognized as a PNG file, why? Because it is not one! Each PNG file starts with its start signature "89 50 4E 47 0D 0A 1A 0A" and ends with its end signature IEND "49 45 4E 44" and currently this is not the case. This is probably because the first one was not complete (it’s doesn't end with IEND) so we will use tshark to extract each cookie value base64 -d to decode them and foremost to extract every files in oneline it's look like that : 

 tshark -r capture.pcapng -Y "http.cookie" -T fields -e http.cookie | 
        sed 's/^[^=]*=//' |
        base64 -d >  base64_decode_output && foremost base64_decode_output

Now we have a directory wich contains 17 PNG we just have to assemble it
